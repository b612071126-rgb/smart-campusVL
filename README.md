# smart-campusVL商丘工学院 · AI 未来概念校园 V3.1

## 启动
1. 解压 `smart_campus_v3.zip`。
2. 用 VS Code 打开整个 `smart_campus_v3` 文件夹。
3. 右键 `index.html`，选择 **Open with Live Server**。
4. 首次加载需要网络连接 Three.js CDN。

## 交互方式
- 点击右侧「AI 教学 / 智慧交通 / 能源网络」模块：切换对应的校园智能系统，扫描环和数据流会切换到对应区域。
- 在三维画面上移动鼠标：附近粒子会被扰动并形成旋涡，模拟交互式数据场。
- 在画面上点击：触发一圈扩散的数据脉冲。
- 拖动鼠标旋转视角，滚轮缩放。

## 本版调整
- 保留三维校园建筑和粒子云，但加入可操作的智慧校园模块。
- 粒子不再只是开场汇聚后静态漂浮，而会根据选择的校园系统持续改变流动状态。
- 增加扫描环、环绕数据轨迹、鼠标局部粒子响应和点击脉冲。
- 右下角署名依然由 Canvas 粒子逐渐汇聚成字，不是静态图片。

如果出现 Three.js 模块加载失败，请检查网络是否能访问 jsDelivr 或 unpkg，再刷新页面。
